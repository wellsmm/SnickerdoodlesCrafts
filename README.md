# SnickerdoodlesCrafts

Website for The Snickerdoodles Wood Design and Patterns.

## Project structure

- `index.html`: website home page (to be added).
- `assets/images/`: logos and website images.
- `.gitignore`: excludes local files, dependencies, and credentials.

## Development

The repository is prepared for a static HTML, CSS, and JavaScript website. No build system has been configured.

After adding `index.html`, preview locally with:

```sh
python -m http.server 8000
```

Open http://localhost:8000 in your browser.

## Publishing

Hosting and a custom domain have not been configured. Choose the hosting provider before adding deployment configuration.

## Updates

Use descriptive commit messages. For larger changes, create a branch and review a pull request before merging into `main`.
